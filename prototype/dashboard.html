Spend per day

Estimated from token counts at API list price. Hover a bar for the day.

SELECT date(ts) AS day, SUM(cost_usd), COUNT(DISTINCT session_id)
FROM messages WHERE role = 'assistant' AND ts >= :since
GROUP BY day ORDER BY day;

    Skill shelf

    One book per skill in P:\skills. Height = times used. Dashed = never triggered.

    SELECT s.name, COUNT(t.id) AS uses
FROM skills s LEFT JOIN tool_calls t
  ON t.tool = 'Skill' AND t.input->>'skill' = s.name
GROUP BY s.name;

    Prompts I keep typing

    Near-duplicate prompts, grouped. Anything typed this often should be a skill or a CLAUDE.md rule.

    -- normalised prompt text, MinHash buckets
SELECT cluster_id, MIN(text), COUNT(*) FROM prompt_clusters
GROUP BY cluster_id HAVING COUNT(*) >= 5 ORDER BY 3 DESC;

    Spend by project

    Where the tokens go.

    SELECT project, SUM(cost_usd) FROM sessions
JOIN messages USING (session_id) GROUP BY project;
